# DreamLives

**An AI-powered simulator for infinite different lives, worlds, and destinies.**

By [Vardark](../README.md)

## Vision

DreamLives lets users explore endless possible lives — different eras, worlds, personalities, and fates — all generated and narrated by AI. Each session is a unique journey through a life that never existed but feels real.

## Core Concepts

- **Life Simulation**: Each "dream life" is a complete narrative arc — birth, growth, choices, consequences, and an ending
- **Infinite Worlds**: Settings range from historical periods to fantastical realms to sci-fi futures
- **Player Agency**: Users make key decisions at turning points that shape the life's trajectory
- **AI-Driven Narrative**: An AI engine generates coherent, emotionally rich storylines in real time
- **Destiny System**: Underlying traits, luck, and world conditions create emergent outcomes

## Planned Features

- [ ] Life generation engine (world, character, timeline)
- [ ] Interactive decision points with branching narratives
- [ ] Character trait and destiny system
- [ ] World-building templates (historical, fantasy, sci-fi, modern, surreal)
- [ ] Life summary and replay
- [ ] Multi-life connections (characters from one life appearing in another)
